# GREYHAVEN — Build Your Squad

GitHub Pages: https://ignissimo.github.io/fluent-mind-lessons/greyhaven/

## Отдельные ученики и стартовый экран

При каждом открытии игры сначала показываются сохранения учеников. Нажмите Continue на нужной карточке или введите имя в New player. Кнопка Players сохраняет текущего ученика и возвращает к списку. У каждого профиля отдельные герой, вещи, команда, этап и ответы. Даже одинаковые имена создают разные профили.

Load squad теперь проверяет файл и создаёт новый профиль, не заменяя чужой прогресс. Старое одиночное прохождение автоматически появляется отдельной карточкой; исходное сохранение не удаляется. Сохранения остаются в текущем браузере. Между устройствами и адресами переносите отряд через Save squad / Load squad.

Первая комната оригинальной серии Fluent Mind Adventures. Спокойная тактическая игра для совместного урока английского, ориентир 35–45 минут без таймера. Фактическая длительность зависит от темпа чтения, письма и обсуждения.

## Запуск

Откройте `downloads/GREYHAVEN.html` в современном браузере. Внутри все изображения и аудио; интернет не нужен. Либо распакуйте ZIP и откройте `index.html`, сохранив папку assets рядом. Для локального сервера: `python3 -m http.server 8765 --directory dist`.

Начните с терминала. Прочитайте приказ, найдите три объекта штаба. Далее кнопка Continue проведёт по шести этапам. Материалы можно открыть повторно через номера этапов и объекты штаба.

## Чтение и звук

▶ рядом с фразой читает её целиком. Нажатие на подчеркнутое слово открывает IPA, озвучку и перевод для основной лексики. Audio → Slow замедляет запись без намеренного изменения высоты голоса; Stop останавливает звук. Автовоспроизведения нет.

Используется американское произношение (macOS Samantha), встроенные MP3. IPA — словарные данные CMUdict-IPA/CMU Pronouncing Dictionary. Medkit составлен из словарных med + kit; armour использует американское armor, spelling armour сохранён из задания. Для вымышленных имён задано авторское чтение, для SMG — названия букв. Редкие динамические фразы без готовой записи могут использовать доступный en-US голос браузера; отсутствие голоса/ошибка показываются явно. Основные учебные фразы и слова имеют встроенные записи.

## Письмо

Поля сохраняются при вводе. Проверка допускает регистр, лишние пробелы, типографский апостроф и финальную пунктуацию. В накладной допускается любой порядок двух выбранных вещей. Используются `a flashlight` и `some extra ammo`. Если работаете в тетради, нажмите Write in notebook, затем преподаватель подтверждает проверенную запись. Имя и позывной всё равно заполняются в пропуске.

## Сохранение и перенос

Автосохранение действует в том же браузере и по тому же адресу. Нельзя рассчитывать на него при переносе HTML или сайта. Кнопка **Save squad** скачивает JSON с именем профиля: формат v1, постоянные ID героя, вещей и напарников, этап, черновики, отметки, уровень 1 и XP. **Load squad** проверяет файл и создаёт отдельный профиль. Ошибочный файл не меняет существующие отряды.

Для будущей миссии нужно открыть её страницу и загрузить этот JSON. Миссия 2 пока не реализована; первая заканчивается открытием ворот и приказом. Повторный финал не дублирует снаряжение и XP.

## Разработка и проверка

- Исходники: `dist/data.js` (тексты), `core.js` (состояние), `app.js` (интерфейс), `audio.js` (воспроизведение), `styles.css`.
- `node --test tests/core.test.cjs` — нормализация, грамматика предметов, prerequisites, импорт и повторный финал.
- `python3 scripts/audio.py` — сборка записей на macOS (say, Samantha, ffmpeg).
- `python3 scripts/package.py` — самодостаточный HTML и ZIP.
- Оригинальные иллюстрации: `art-source/`; оптимизированные WebP: `dist/assets/`.
- Словарь: https://github.com/menelik3/cmudict-ipa ; оригинальный CMU: https://github.com/cmusphinx/cmudict . Лицензия CMU сохранена в docs и dist/assets.

Ограничения: автоматическая проверка письма сравнивает короткие фразы с моделями, не оценивает свободное сочинение; выбор команды и предметов свободный внутри заданных ролей; нет боя, аккаунтов, облачной синхронизации и следующей комнаты. Нужны динамики или наушники. На планшете используется вертикальное расположение штаба и панели; отдельная телефонная версия не разрабатывалась.
