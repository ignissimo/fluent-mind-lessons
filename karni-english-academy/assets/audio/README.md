# Recorded reading

132 local M4A files: 130 question-and-option readings, a menu prompt, and a completion prompt. Generated locally with macOS Daniel (en_GB), rate 145, encoded as AAC at 64 kbit/s. manifest.json records the text for each clip. Blank spaces are spoken as “blank”.

Question option order is stable for each source item and matches the recording, including during mistake review. The browser speech API is used only if a recording cannot play. No student input or teacher observations are included in these recordings.
