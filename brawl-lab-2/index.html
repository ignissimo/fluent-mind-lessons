🎓 Teacher Guide: Brawl Stars basics

Brawler = playable fighter; Attack = regular move; Super = charged special ability; Gadget = additional ability; Star Power = passive upgrade; Hypercharge = temporary enhanced state for eligible characters; Gem Grab = team mode collecting gems; buff = make stronger; nerf = make weaker. Fictional stats and challenges in this lesson are NOT official game data.

Before Teacher Approved, ask for a spoken reason, consequence and alternative. Useful words: damage, range, shield, cooldown, balanced, unfair, retreat, cover, because, although, if.
