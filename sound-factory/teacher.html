FLUENT MIND / CRACK THE CODE / PART 08

The Sound Factory

Восьмая часть курса обучения чтению. Доступна самостоятельно: части 1–7 не нужны для входа. Все ученические инструкции — на простом английском.

Открыть игру →

Перед занятием

  • Подготовьте тетрадь, карандаш и наушники или колонки. Начните с прослушивания rain, day, cake. Новый звук — /eɪ/: один гласный звук, хотя в IPA два символа.
  • Нажмите Listen и убедитесь, что звук слышен. Встроены локальные записи слов и предложений голосом Daniel (British English); при недоступности файла используется голос браузера. При отсутствии обоих вариантов прочитайте пример сами — игра продолжит работать.
  • Покажите Help и Sound guide. Ошибки не отнимают баллы, времени на ответ нет. Разрешите сначала послушать, затем ответить или прочитать вместе.
  • Сохранения локальные, только в этом браузере и на этом устройстве. Перед новым учеником выгрузите отчёт. Teacher → New student → Clear this mode очищает только текущий режим; Homework очищается отдельно.

Как помогать

Не требуйте угадать. Предложите послушать слово, сказать его, выделить /eɪ/, затем выбрать код. Для magic E сравните cap /kæp/ и cape /keɪp/, tap /tæp/ и tape /teɪp/, mad /mæd/ и made /meɪd/. Последняя E не произносится.

AI часто стоит внутри слова, AY — в конце; это опора для слов урока, а не универсальное правило для всех английских слов. В задаче без контекста на /eɪ/ нужно выбрать все три варианта: AI, AY, A-E.

Задания на два звука используют слова-образцы и порядок стрелки: например, moon → book означает /uː/ → /ʊ/. Используется британская IPA: dog /dɒg/, bed /bed/.

Карточки нажимаются мышью, пальцем и клавишами Tab / Enter / Space. Нажмите карточку в строке ответа, чтобы вернуть её вниз. Порядок карточек и вариантов перемешан; одинаковые буквы и слова представлены отдельными карточками.

В Sentence Lab после сборки ученик читает вслух и отмечает «I read it aloud». В первом и пятом предложениях есть замена cake ↔ game: получится другое осмысленное предложение с тем же звуком.

Честный учёт результата

  • Правильный ответ: 10 XP один раз. Повторные прохождения не увеличивают XP за тот же сигнал.
  • Help → Show Answer позволяет свериться. После Show Answer правильный ответ также отмечается как выполненный с помощью, в том числе после перезагрузки. «Practise with teacher» отмечает работу с помощью и не выдаёт XP за самостоятельный ответ. Позже можно решить самому и получить обычные 10 XP.
  • Тетрадная миссия: 5 XP один раз после подтверждения ученика. Компьютер не проверяет тетрадь или устное чтение.
  • Ачивка выдаётся за все решённые или проработанные с помощью задачи модуля и подтверждённую тетрадь, если она есть. Отчёт отдельно показывает самостоятельные ответы и работу с помощью.
  • Число собранных слов — уникальные слова из десяти целевых, встретившиеся в самостоятельно решённых задачах. Финальный экран доступен всегда; SYSTEM RESTORED появляется только после восстановления шести учебных модулей.

Песня: временный режим

Read the Code — Suno ↗. Откройте песню в отдельной вкладке. Управляйте воспроизведением в Suno, а сценами — кнопками Previous Scene / Next Scene в игре. Точной синхронизации нет. Внешний сервис может потребовать вход.

Доступного MP3 и подтверждённого полного текста песни при сборке не было. Поэтому Play & Decode использует восемь явно обозначенных тренировочных пропусков по лексике ТЗ. Это не восстановление точного текста песни. Show Lyrics объясняет это и показывает practice lines. Для тетради можно записать две услышанные строки или два тренировочных примера.

Для занятия сегодня: Teacher → Local song / lyrics позволяет выбрать аудиофайл и вставить имеющийся у вас текст. Они действуют только в открытой вкладке. Затем откройте модуль 04. При перезагрузке файл нужно выбрать заново.

Постоянная замена на MP3

Поместите разрешённую копию файла в assets/read-the-code.mp3. В data.js установите song.localSrc: 'assets/read-the-code.mp3'. В song.lyrics задайте точный текст. Для синхронизации задайте song.cues — массив из семи возрастающих моментов начала сцен в секундах, например [0, 20, 40, 60, 80, 100, 120]; замените пример реальными временами. Без cues сцены остаются ручными. Измените восемь задач song на реальные пропуски после получения текста. Запуск любого звука — только по действию пользователя.

Изолированные фонемы

Sound guide по умолчанию воспроизводит целые слова-образцы — это прямо подписано. Символы IPA не передаются обычному TTS. Через Teacher → Phoneme recordings можно загрузить собственную запись конкретного звука. Записи действуют только в текущей вкладке и не загружаются на сервер.

Homework · 10–15 минут

Пять сопоставлений IPA и слов, пять слов из букв, два предложения для чтения и сборки, одна тренировочная строка и выбор трёх кодов. В конце — пять слов в тетради. Прямая ссылка Listen to the song доступна вверху каждого задания Homework; сохранения Homework остаются отдельно. Для иллюстраций можно вернуться в Menu → The Broken Song → Watch & Listen.

Сохранение и материалы

Ключи: fma-sound-factory-8-main, fma-sound-factory-8-homework. Сохраняются текущая задача, карточки, завершения и отметки тетради. Другие уроки и старый Crack the Code не меняются. В приватном режиме или при запрете localStorage возможна работа только до закрытия вкладки; игра показывает предупреждение.

Teacher показывает ответы и переходы. В Mission report кнопка Download report сохраняет TXT. Все SVG созданы для этого урока; внешние библиотеки и сетевые шрифты не нужны. Код и данные разделены, чтобы следующие части курса могли повторить визуальный язык с другими заданиями.
