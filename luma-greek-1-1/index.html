🎯 Твоя задача

Продолжение появится здесь, когда будет готова следующая глава.

Голосовой ответ запускается только по нажатию. Разреши доступ к микрофону; для распознавания может понадобиться интернет. Браузер может передавать речь своему сервису распознавания. Приложение не хранит аудиозаписи. Проверяются распознанные слова и фраза, а не качество произношения. Для прохождения нужен работающий микрофон и поддержка распознавания речи в браузере.
